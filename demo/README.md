# Faust — демо (крок 1)

## Що це

Статичний макет сайту нічного клубу Faust у двох HTML-файлах. Жодної збірки, жодних залежностей — відкривається подвійним кліком у будь-якому браузері.

- `index.html` — головна: hero з проміневою анімацією, про клуб, фішки бару, атмосфера, локація, футер.
- `menu.html` — вітрина меню з категоріями, картками позицій і липкою навігацією.

Це макет для узгодження дизайну й структури із замовником. Реального застосунку, бази даних, адмінки й реальних фото тут ще немає.

## Як відкрити

Двічі клацнути на `index.html`. Інтернет потрібен лише для завантаження шрифтів (Google Fonts) — решта працює повністю офлайн.

## Плейсхолдери — потребують підтвердження замовника

Увесь текст, ціни, назви коктейлів і контакти — заглушки для демонстрації верстки, не реальні дані:

- Адреса, телефон, посилання на Instagram/Telegram у розділі «Знайти нас» — вигадані.
- Назви, склад і ціни коктейлів, вин, пива та снеків — приклади, не фінальне меню.
- У розділі «Про клуб» вказано вхід «21+», а у футері — вік «18+». Це розбіжність макета: потрібно уточнити в замовника, яке обмеження діє насправді, і привести до одного значення.
- Місткість залу («180 місць») — приклад, не реальна цифра.
- Фото відсутні свідомо: усі візуальні блоки — CSS-градієнти й заглушки-монограми.
