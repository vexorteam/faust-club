# Contributing

This is a commissioned, closed-source project built for a single client. It does not accept external contributions, issues, or pull requests from the public.

## Working on this repository

- Commits follow [Conventional Commits](https://www.conventionalcommits.org/): `feat(scope): description`, `fix(scope): description`, `docs(scope): description`, and so on.
- Design, scope, and content decisions are approved by the project owner before implementation.
- Development proceeds one step at a time; each step is reviewed before the next one starts.
- Dependencies are kept to the agreed set — adding a new one requires discussion first.
