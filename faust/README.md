# Faust — сайт нічного клубу

Next.js 16 (App Router) · TypeScript strict · self-hosted шрифти · design-tokens з референс-макета Club X.

## Швидкий старт

```bash
npm install
npm run dev       # http://localhost:3000
```

## Скрипти

- `npm run dev` — розробка
- `npm run build` — прод-збірка (перевірено, збирається чисто)
- `npm run start` — запуск прод-збірки
- `npm run lint` — ESLint
- `npm run typecheck` — tsc --noEmit
- `npm run format` / `format:check` — Prettier (`@fxhxyz/prettier-config`)
- `npm test` — Vitest (125/125 проходять: нічний графік, схеми відповідей API, шар помилок, сесія адміна, схеми й дії адмінки, форматування цін, генерація адрес категорій)

## Змінні оточення

Скопіюйте `.env.example` у `.env.local` і заповніть. Без `MENU_API_URL` сайт збирається,
але меню береться зі статичних даних (у розробці) або лишається порожнім (у проді),
а вхід в адмінку не працює — за нього відповідає той самий API.

## Адмінка

`/admin` — закрита частина для персоналу клубу: вхід за поштою й паролем,
сесія в httpOnly-кукі, перевірка на боці Python-API. Сторінки не індексуються
і ніколи не кешуються.

Розділи: **Позиції** (`/admin`) — список меню по категоріях із пошуком, перемикачем
«Є / Немає» та сортуванням; **Категорії** (`/admin/categories`) — назви, адреси,
видимість, порядок; **Атмосфера** (`/admin/atmosphere`) — плитки на головній.

Адмінка працює **тільки з піднятим API** — саме він перевіряє пароль і зберігає дані.
Без `MENU_API_URL` сторінка входу відкриється, але увійти буде нікуди.
Завантаження фотографій зʼявиться наступним кроком.
