# Security Policy

## Supported Versions

There are no tagged releases yet — the project is in active pre-release development. Only the `main` branch is maintained.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately by email to **security@faust.club** instead of opening a public issue. Include as much detail as possible so the report can be reproduced.

We will acknowledge reports within a reasonable timeframe and address confirmed issues before any public disclosure.

## Current Scope

The public site is currently a static demo with no forms, accounts, or data submission — there is no attack surface beyond serving static files. An authenticated admin panel with file uploads is planned for a later development stage; this policy will be expanded once it exists.
