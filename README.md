# Faust

**[Українська](#українська) · [English](#english)**

---

## Українська

Промо-сайт нічного клубу Faust: атмосферна головна сторінка з анімованим hero та окрема сторінка меню-вітрини бару. У складі проєкту також буде закрита адмін-панель для редагування меню власником клубу.

**Статус:** крок 1 з 13 — демо для замовника (завершено).

Проєкт розвивається від статичного демо до повноцінного застосунку. Поточна стадія — самодостатня HTML-демка без збірки, яка показує фінальний вигляд головної сторінки й меню.

### Як відкрити демо

Відкрити `demo/index.html` подвійним кліком у будь-якому браузері. Збірка не потрібна, `node_modules` немає. Деталі — у `demo/README.md`.

### Що не входить у версію 1.0

Бронювання столиків, афіша подій і продаж квитків, кошик і оплата, особисті кабінети відвідувачів.

## English

Promo website for Faust, a night club: an atmospheric homepage with an animated hero section and a separate menu showcase page for the bar. The project will also include a private admin panel for the club owner to manage the menu.

**Status:** step 1 of 13 — client demo (completed).

The project grows from a static demo into a full application. The current stage is a self-contained, build-free HTML demo showing the final look of the homepage and menu.

### How to open the demo

Open `demo/index.html` with a double click in any browser. No build step, no `node_modules`. See `demo/README.md` for details.

### Out of scope for v1.0

Table reservations, an events calendar or ticket sales, a cart or checkout, and visitor accounts.
